How the numbers are made

We fit a ridge regression (λ=0.25) on the sealed DefiLlama snapshot to predict log(mcap/tvl) from protocol features: TVL, 7d growth, age, chain count, and major-chain presence. The model uses 128 bearers (protocols with live tokens and positive TVL).

Held-out tests: leave-one-out error ratio × baseline; walk-forward (time-ordered) error ratio × baseline. Residual IQR: [, ].

Token odds per category start from Laplace-smoothed launch share, shrunk toward the global share, then decay with protocol age (factor 0.98 per year). Final odds clamped to [2%, 95%].

Implied value = clamp(tvl × exp(w·x) × token_odds, max($250k, 2%×tvl), $100T). Scenario bands use residual quartiles.

Farm verdict prices a 3–12 step plan with capital/gas costs; $/hr = implied ÷ hours.

Every figure is the entry's own claim, derived from the sealed snapshot alone.
